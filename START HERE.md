# Meet Nikhil's Advisor Agents

Start with one real piece of work: a page, a proposal, a confusing decision, or a spreadsheet. Give it to the agent whose job fits.

1. Download and unzip this folder, or attach the ZIP to your AI tool if it can read archives.
2. Ask: **“Read INSTALL.md and install these as named agents for this project. Keep my existing settings and custom agents.”**
3. Start a new session after installation. Try one of the prompts below.

For native agents, use **Claude Code** or **Codex** with custom-agent support. If you use a regular chat or a tool that cannot install custom agents, open this folder in one of those tools. Merely attaching the ZIP does not create agents in every chat app.

## A first task

- **Jackson:** “Delegate to Jackson: pressure-test this proposal. What assumption could make it fail, and what is the smallest way to check it?”
- **Sylvia:** “Delegate to Sylvia: turn this idea into the smallest useful version we can build. Define what success looks like.”
- **Nikhil:** “Delegate to Nikhil: inspect this journey using attention, intention, and action. Recommend a concrete change while preserving our visual style.”
- **Taichi:** “Delegate to Taichi: walk the new-user journey and find the strongest barrier to first value. Suggest one change we can learn from.”
- **Brendan:** “Delegate to Brendan: implement this change, verify the important user path, and show me what passed.”
- **Hannah:** “Delegate to Hannah: analyse this file. What can we conclude from the numbers, and what can't we conclude?”
- **Glyndon:** “Delegate to Glyndon: first help define the entities, sources, and quality rules for our data, then audit this sample.”

Give the agent your goal, relevant files or links, constraints, and what you want back. You can work with just one agent. For two independent questions, ask for two agents and a combined result. For a sequence, ask for one to finish before the next begins.

The main assistant coordinates the work. Each named agent investigates and acts within its role and the access your tool permits. At every ten work turns, it should ask whether a small improvement to its way of working would help. You can accept a suggestion, give a different one, or continue without changing it.
